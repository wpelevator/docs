signatures

Generate Ed25519 keys, sign files and verify signatures in the WordPress, minisign and OpenSSH formats.

Open as Markdown

Generate Ed25519 keys, sign files and verify signatures in three formats that share one key: the detached signature that WordPress core's verify_file_signature() checks, minisign and OpenSSH (ssh-keygen -Y sign). It uses only node:crypto, with no runtime dependencies.

Install

npm install @wpelevator/signatures

Requires Node.js 22.12 or later.
