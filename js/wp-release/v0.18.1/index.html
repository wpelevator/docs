WP Release

Build and release WordPress plugins, themes, and packages.

Open as markdown

@wpelevator/wp-release provides a CLI and library for building release directories and ZIPs, creating checksums and signatures, checking versions, extracting and compiling translations, and deploying to WordPress.org SVN or Git repositories.

The wp-release-zip, wp-release-checksums, wp-release-sign, and wp-release-deploy-svn GitHub Actions expose the same commands in workflows.

For projects that don't use Node.js or JavaScript tooling, PHP Changesets (wpelevator/php-changesets) runs the same changeset release workflow with PHP and Git alone: changeset add, status, version and tag read the same changeset files and match the options of the changeset-* commands described in Changesets support.

WordPress.org themes are released by uploading a ZIP, so deploy-svn is for plugins only. Use zip to build a theme upload. Packaging and deployment options follow familiar community tools to ease migration; the comparison explains the differences.

Install

Node.js 22.12 or later is required. SVN deployments also require the svn command line client. Git deployments and changeset commands require Git.

The package is an ES module with TypeScript declarations. CommonJS projects can load it with require( '@wpelevator/wp-release' ) on Node.js 22.12 or later.
