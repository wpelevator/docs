Deploy

Choose between WordPress.org SVN, a Git repository and the configured packages of a monorepo.

Open as Markdown

Deploys publish the files of a release. Pick the target:

I want to Command Page
Publish a plugin to WordPress.org deploy svn Deploy to WordPress.org
Release built files to a distribution repository deploy git Deploy to a Git repository
Release every package of a monorepo to its own targets deploy git --release-ref, deploy svn --release-ref Deploy configured packages

All three read files like zip does: with .distignore and --exclude, so build first and deploy what you built. Each supports --dry-run, which runs everything except the write, and a failed check exits with 2. WordPress.org themes are released by uploading a ZIP, so deploy svn is for plugins only: use zip for a theme.
