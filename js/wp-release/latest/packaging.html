Build, verify and sign

Choose the command that turns a plugin or theme directory into a release you can trust.

Open as Markdown

Everything between your source directory and a published release is one command. Pick the task:

I want to Command Page
Get the ZIP WordPress.org accepts zip Build a release ZIP
Leave out node_modules/, tests and other dev files --exclude, .distignore Choose which files ship
Stop a release when the versions disagree version-check Check versions
List every shipped file with its hash checksums, zip --checksums Write a checksums manifest
Prove a ZIP or an installed plugin is unchanged verify Verify a ZIP or directory
Sign the ZIP and the manifest keygen, sign Sign releases

Each command exits with 2 when a check fails, so any of them can stop a CI job. The quickstart runs the first four in a minute.
