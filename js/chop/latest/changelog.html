Changelog

What changed in each release.

0.2.1 (2026-11-07)

  • Make the exported DEFAULT_SETTINGS report the real maxConcurrency default of the number of CPUs, which createConfig used to compute separately after overriding the placeholder value. (c075de5)
  • Move the detailed usage documentation from the README into topic pages of the docs/ directory, so that the docs site has a guide for each area besides the reference. (da8652c)
  • Publish the docs/ directory in the npm package, so that agents and editors can read the documentation of the installed version. (da8652c)

0.2.0 (2026-11-04)

  • Add the allowedInputFormats and autoFormats settings (CHOP_ALLOWED_INPUT_FORMATS and CHOP_AUTO_FORMATS), and pick the negotiated format by the q-values of the Accept header. (496d04d)
  • Add an internal AWS Signature Version 4 signer for S3 and a per-request header hook on the HTTP origin, as groundwork for an S3 origin. (a038143)
  • Load originals from an HTTP(S) origin with CHOP_ORIGIN, or from allow-listed hosts named in URLs with CHOP_ALLOWED_HOSTS, through a pluggable origin interface, with pinned and blocked-address-checked connections, no redirects, a streaming size cap, timeouts and a separate fetch limit, in both the query and cloudflare schemes. (971a1cf)
  • Add an S3 origin: CHOP_ORIGIN=s3://bucket[/prefix] reads originals from AWS S3 or an S3-compatible service (SeaweedFS, MinIO, R2) with AWS Signature Version 4 requests, configured with CHOP_S3_ENDPOINT, CHOP_S3_REGION, CHOP_S3_PATH_STYLE and the CHOP_S3_* or AWS_* credentials, with the S3 error codes in the operator log. (2099b59)

0.1.1 (2026-11-04)

  • Fix the README, which still said that the package is not published. (aaa907b)

0.1.0 (2026-11-04)

  • Add Chop, an HTTP image server with AVIF and WebP negotiation from the Accept header, resize, crop and letterbox, Cloudflare-style URLs through pluggable URL schemes, and a library and CLI. (2a83fd3)
  • Publish the package to npm. (93cd789)
