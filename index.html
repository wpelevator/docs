WP Elevator Docs

Guides and references for the packages of the WP Elevator monorepo.

JS packages

  • checksums

    Hash bytes and files, and write, read and verify checksum manifests in the sha256sum and WordPress.org formats.

  • chop

    An HTTP image server that resizes images on request and picks AVIF, WebP or the original format from the Accept header.

  • fileset

    Select the files of a directory with gitignore-style rules and sync another directory to match, copying only what changed.

  • signatures

    Generate Ed25519 keys, sign files and verify signatures in the WordPress, minisign and OpenSSH formats.

  • subtree-split

    Split a monorepo directory into its own history, with the same commit hashes as git subtree split.

  • wp-gettext

    Extract translatable strings from WordPress sources, write POT files, compile PO files to MO, JSON and PHP, and audit catalogs.

  • wp-release

    Build, verify, version and deploy WordPress plugin and theme releases from one CLI, a library or GitHub Actions.

  • zip

    Create reproducible ZIP archives from files and buffers, and safely list and extract them.

PHP packages

  • php-changesets

    Prepare multi-package releases for PHP projects and monorepos with changeset Markdown files, PHP and Git.
