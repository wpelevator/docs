Colophon

How the WP Elevator documentation site is made and published.

This site is plain static HTML generated by Eleventy. There is no framework and no client-side router. Pages are Liquid templates and Markdown, and a small optional script adds the mobile menu, the version switcher, the copy buttons and search. Everything else works without JavaScript.

Content lives with the code

Each package owns its documentation as Markdown in its own docs/ folder in the open source monorepo. Before each build the current docs are staged as latest, and the docs of every released version are read from its Git release tag, so older versions stay available at their own addresses.

Built for readers and agents

  • Every page is also published as plain Markdown, linked with rel="alternate" and available through the Copy as Markdown and Open as Markdown buttons.
  • Code is highlighted at build time and every code block has a copy button.
  • Search uses Pagefind, which indexes the built pages in the browser without a server. Only the latest docs are indexed.
  • Page titles are unique across packages and versions, and older versions point search engines to the latest page with a canonical URL.

Design

One mobile-first stylesheet written in modern CSS: design tokens, container queries, nesting, logical properties and light-dark() for the light and dark color schemes. Text is set in the system font, headings in italic.

Publishing

A GitHub Actions workflow builds the site on every change to the docs and publishes the static output to GitHub Pages from the public wpelevator/docs repository.
